## Hi there 👋

I build practical security automation projects in Python, with a focus on clear findings and analyst-friendly workflows.

### Security Automation Toolkit

A collection of small, defensive tools built with Python’s standard library and synthetic demo data.

- [SOC Alert Triage Automator](https://github.com/classified20/security-automation-toolkit/tree/main/soc-triage) — scores sample alerts with visible rules and produces analyst notes.
- [Cloud Security Posture Checker](https://github.com/classified20/security-automation-toolkit/tree/main/cloud-posture) — reviews a configuration snapshot for risky IAM, public storage, and exposed admin ports.
- [Vulnerability Prioritization Pipeline](https://github.com/classified20/security-automation-toolkit/tree/main/vulnerability-prioritizer) — combines CVSS with asset exposure and business context to order remediation work.

[View the toolkit repository](https://github.com/classified20/security-automation-toolkit)

All examples use fictional data. The tools are read-only demos and do not connect to or change live systems.
